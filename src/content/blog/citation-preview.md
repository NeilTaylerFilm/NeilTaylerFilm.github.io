This is a visual mockup. The links below demonstrate source labels; they do not support a factual claim in this sample text.

An article citation can sit right beside the sentence it relates to, such as this sample source [BFI article](https://www.bfi.org.uk/ "cite"). The link is still a normal Markdown link in the file: `[BFI article](https://www.bfi.org.uk/ "cite")`.

For several source types together, a sentence can end with [BFI article](https://www.bfi.org.uk/ "cite") [video at 1:30](https://www.youtube.com/watch?v=HAkxnRaTW2Q&t=90s "cite") [book title, p. 42](https://www.penguin.co.uk/ "cite").

A longer set can include another source too: [BFI article](https://www.bfi.org.uk/ "cite") [video at 1:30](https://www.youtube.com/watch?v=HAkxnRaTW2Q&t=90s "cite") [book title, p. 42](https://www.penguin.co.uk/ "cite") [MUBI source](https://mubi.com/ "cite").

A pair of sources works the same way: [BFI article](https://www.bfi.org.uk/ "cite") [book title, p. 42](https://www.penguin.co.uk/ "cite").

The label can include a page number for a book reference, as above.

Links without the `cite` title marker keep the usual appearance, like this [ordinary Markdown link](https://astro.build/).
