Publishing.

Your complete reference for adding posts, projects, and slideshow images to your website.

Two separate steps: (1) Prepare on your Mac, (2) Publish to GitHub. Saving a file does not update the live website.

Section 1

Adding a blog post

Step 1

Create the file

Open src/content/blog/ in Finder. Create a new plain-text file named your-post-name.md.

Use lowercase and hyphens. Example: a-week-in-london.md

Step 2

Paste this template

---
title: 'Your post title'
date: 2026-09-14
categories:
  - Photography
description: 'A short summary for search results.'
excerpt: 'One or two sentences for the homepage card.'
draft: true
---

Write your article here.

## A section heading

More writing goes here.

Leave a blank line between paragraphs.
Step 3

Understand the frontmatter

FieldWhat to put
titleThe title readers see. Keep quotes around it.
datePublication date: YYYY-MM-DD
categoriesOne or more subjects, each indented with a dash
descriptionShort summary for search and social sharing
excerptBrief intro shown on the homepage (1–2 sentences)
draft: trueKeeps the post hidden from the public website
Step 4

Format your writing

## A main section
### A subsection
#### A deeper level

**Bold text** and *italic text*

[Click this link](https://example.com)

- Bullet point one
- Bullet point two

> A quotation goes here.

Don't repeat the title as a # heading—the website already displays it.

Section 2

Adding a photography project

Step 1

Put pictures in a folder

In Finder, open src/assets/. Create a folder named after your project, like london-at-night/. Copy your JPEG images into it.

Step 2

Create the project file

Open src/content/photography/. Create london-at-night.md and paste:

---
title: 'London at night'
year: 2026
location: 'London'
category: 'Street'
description: 'Photographs from evening walks.'
coverImage: /assets/london-at-night/bridge.jpg
draft: true
images:
  - src: /assets/london-at-night/bridge.jpg
    alt: 'A lit bridge crossing the river at night'
    caption: 'An evening by the river.'
  - src: /assets/london-at-night/street.jpg
    alt: 'People walking under shop lights'
---

Write a short introduction to your photographs here.
Step 3

Key fields

  • title — Project name shown to visitors
  • coverImage — Picture shown on the Photography index card
  • images: — List of photographs in the gallery
  • alt — Description for accessibility (not visible)
  • caption — Optional text shown below the image
Section 3

Adding pictures to the slideshow

The slideshow is the large rotating image at the top of the Photography tab. It is separate from project galleries.

Step 1

Open the slideshow list

In Finder, open src/data/featured.ts. Replace the entire contents with:

type FeaturedPhoto = {
  src: string;
  alt: string;
  caption?: string;
  project?: string;
  width: number;
  height: number;
};

export const featured: FeaturedPhoto[] = [
  {
    src: '/assets/london-at-night/bridge.jpg',
    alt: 'A lit bridge crossing the river at night',
    caption: 'An evening by the river',
    width: 6000,
    height: 4000,
  },
];

export const featuredIsDemo = false;
Step 2

Get image dimensions

In Finder, select a photo and press Command-I. Under More Info → Dimensions, note the width and height.

Step 3

Add or remove slides

Copy a whole { ... } block and paste it before the final ];. Remove a block to delete a slide. The first block is the first slide visitors see.

Section 4

Previewing your changes

This is your private rehearsal. Visitors cannot see it.

Step 1

Open Terminal

Press Command-Space, type Terminal, press Return.

Step 2

Start the preview server

cd /Users/neil/Documents/CodingProjects/neiltaylerfilm.github.io
npm run dev:stop
npm run dev

Open the address Terminal prints (usually http://127.0.0.1:4321/). Drafts appear here.

After editing text: save and refresh the browser.
After adding/changing images: run npm run dev:stop then npm run dev again.

Section 5

Publishing to the live website

Step 1

Mark drafts as published

Change draft: true to draft: false in each post or project you want visitors to see.

Step 2

Run checks

npm run check
npm test
npm run build
npm run verify

If any command reports an error, stop here. Copy the error and ask for help.

Step 3

Preview the public version

npm run preview -- --background

Open the printed address (usually http://127.0.0.1:4322/). Drafts should be absent.

Step 4

Send changes to GitHub

git branch --show-current          # Should say "main"
git status --short                 # See what changed
git add src/content/blog/your-post.md
git add src/data/r2-images.json    # If you uploaded photos
git commit -m "Add new blog post"
git push origin main
Step 5

Wait for deployment

  1. Open GitHub Actions
  2. Find the latest Deploy Astro to GitHub Pages run
  3. Wait for green ticks on both build and deploy
  4. Open neiltaylerfilm.github.io and refresh
