Domain Setup.

Connect a custom domain like www.neiltaylerfilm.com to your website.

Prerequisite: You must have access to your Cloudflare account where the domain is managed.

Custom domain requirements

The domain must be managed through Cloudflare. If it's registered elsewhere (GoDaddy, Namecheap, etc.), transfer it first or point the nameservers to Cloudflare.

Add the domain to Cloudflare

Step 1

Open Cloudflare Dashboard

Go to dash.cloudflare.com and sign in.

Step 2

Add a new domain

Click Add a domain. Enter your domain name (e.g. neiltaylerfilm.com). Follow the prompts to add it to your account.

Configure DNS records

Once the domain is added, add these DNS records:

TypeNameContentProxy
A @ 185.199.108.153 Proxied (orange)
A www 185.199.108.153 Proxied (orange)
CNAME www neiltaylerfilm.github.io. Proxied (orange)

Important: The proxy must be ON (orange cloud) for the custom domain to work correctly with GitHub Pages.

Configure GitHub Pages

Step 1

Open repository settings

Go to GitHub repository settings.

Step 2

Add custom domain

Under Pages → Custom domain, enter your domain and click Save.

Step 3

Enable HTTPS

Check Enable HTTPS. If it fails, wait a few minutes and try again — Cloudflare needs to propagate first.

Verify everything works

  • Visit www.neiltaylerfilm.com — should show your site
  • Visit neiltaylerfilm.com (without www) — should redirect or show the same
  • Check the padlock icon in the address bar — confirms HTTPS is active

DNS propagation can take up to 48 hours. If your domain doesn't work immediately, wait and check back later.
