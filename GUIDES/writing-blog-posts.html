Writing Blog Posts.

Everything you need to write and format a blog post — from headings to images to citations.

File location: Put each post in src/content/blog/ as a plain-text .md file named your-post-title.md.

Frontmatter

The top block of metadata. Always starts and ends with ---.

---
title: 'Your blog post title'
date: 2026-09-14
categories:
  - Photography
  - Travel
description: 'A short summary (1 sentence) for search engines.'
excerpt: 'What readers will find on this page (1–2 sentences).'
coverImage: '/assets/writing/your-cover.jpg'
draft: true
---
FieldWhat goes here
titleThe post title shown at the top
datePublication date: YYYY-MM-DD
categoriesOne or more labels, each on its own line with a dash
descriptionShort summary for search results and social sharing
excerptBrief intro for the homepage card (1–2 sentences)
coverImageOptional blog card thumbnail and social preview. Use a local image path or a direct R2 image URL listed in src/data/r2-images.json; the site displays it in a 16:9 frame by cropping the original in the browser, without saving a new crop.
draft: truePost is hidden until you change this to false

Keep quotes around titles and descriptions. They often contain special characters. Example: title: 'A week in Paris'

Headings

## A main section
### A subsection
#### A deeper level

Use these to split your post into scannable sections. Don't repeat the title as a heading — the website already shows it.

Images

Store images in src/assets/<topic>/.

<img src="/assets/writing/cover.jpg" alt="A sunset over Paris rooftops" />
  • src — Path to the image file, relative to the site root
  • alt — Text description for screen readers and SEO. Always include this.

Adding an image: (1) Place the file in src/assets/, (2) Use /assets/foldername/image.jpg in your Markdown.

Citations

Write footnotes using bracketed numbers:

Some claim that this technique dates back to the 1920s.[^1]

[^1]: First cited in A. Author, _Title of Work_ (Publisher, Year), page 42.

Each ^number appears as a superscript in the article. The full citation is rendered at the bottom.

For Obsidian users

Your posts are standard Markdown files. Obsidian renders them with a preview panel — no extra setup needed.

  • Open any .md file in Obsidian to preview your formatting
  • Links starting with http open in your browser; everything else opens inside Obsidian
